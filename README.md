# PasoCalc — PC のための軽量・構造化された電卓アプリ

**PasoCalc は、電卓の手軽さと Excel の柔軟性を両立した “行ベースの数式ワークスペース” です。**  
行ごとに数式を入力し、上から順に評価されるため、計算結果を自然に参照しながら連続計算できます。  
Excel を開くほどではないけれど、電卓では物足りない──  
そんな場面に最適化した軽量計算ツールです。  

## ✨ 特徴

### ✔ 行ベースの計算モデル  
- 各行は「変数名・別名・数式・結果」を持つ  
- 上から順に自動計算され、依存関係が自然に解決  
- `[alias]` 記法で任意の別名を変数として利用可能
- 別名はリファクタリングにより後から変更可能

### ✔ 高速で安全な式評価  
- exp4j による高速評価  
- `sin_deg`, `cos_deg`, `tan_deg` など **度数法関数を独自拡張**  
- `^` も独自拡張により自動で `pow(a, b)` に変換  
- 数式の書き心地を最大限シンプルに

### ✔ 実用的でシンプルな UI  
- ダーク／ライトテーマ  
- メモ欄（別ウィンドウ編集対応）  
- 関数一覧パネル  
- ショートカットキー  
  - Ctrl+↑ / Ctrl+↓（行移動）  
  - Ctrl+D（行複製）  
  - Ctrl+BS（行削除）  
  - Ctrl+R（再計算）  

### ✔ JSON 保存／読み込み  
- `.pcale` ファイルとして計算状態を丸ごと保存  
- コメント・丸め桁数・行データを完全復元  
- 計算ログとしても活用可能

## ▶️ 使い方

1. ZIP を展開して `PasoCalc.exe` を起動  
2. 行に数式を入力（例：`1+1`）  
3. Enter または Tab で計算  
4. 別名（例：`a`, `b`, `temp1`）を設定すると、  
   下の行で `[a]` のように参照可能  
5. 「下に追加」ボタンで行を追加  
6. 行を上から順に評価し、依存関係を自動解決

```
例:二次方程式の解
a = 2
b = 8
c = 4
temp1 = sqrt(([b]^2) - 4 * [a] * [c])
x1 = (-[b] + [temp1]) / (2 * [a])
x2 = (-[b] - [temp1]) / (2 * [a])
```
## 📘 関数と型付きリテラル

PasoCalc には、標準的な数学関数に加えて、  
**日時計算・度数法三角関数・基数変換・型付きリテラル**  
といった独自拡張が多数用意されています。

### ✔ 関数（Functions）

- `sin(x)`, `cos(x)`, `tan(x)`  
- `asin(x)`, `acos(x)`, `atan(x)`  
- `sinh(x)`, `cosh(x)`, `tanh(x)`  
- `sin_deg(x)`, `cos_deg(x)`, `tan_deg(x)`（度数法）  
- `datetime("YYYY-MM-DD HH:MM:SS")`  
- `diff_datetime(a, b)`  
- `to_hex(x)`（10進 → 16進）  
- `to_bin(x)`（10進 → 2進）  
など多数。

### ✔ 型付きリテラル（Typed Literals）

PasoCalc の大きな特徴として、  
**数値や日時を “型付きリテラル” として記述できます。**

#### 🔹 入力リテラル（式に直接書ける）

| リテラル | 説明 | 例 |
|---------|------|------|
| `hex[FF]` | 16進リテラル | `hex[FF] + 1 → 256` |
| `bin[1010]` | 2進リテラル | `bin[1010] * 2 → 20` |

これらは内部で自動的に 10進数へ変換され、  
exp4j に安全に渡されます。

#### 🔹 表示リテラル（計算結果の表示形式）

| リテラル | 説明 | 例 |
|---------|------|------|
| `datetime[2026-09-11 12:34:56]` | 日時表示 | `format_datetime(x)` の結果 |
| `date[2026-09-11]` | 日付表示 | `date("2026-09-11")` の結果 |
| `time[12:34:56]` | 時刻表示 | `time("12:34:56")` の結果 |

入力は関数形式、  
表示はリテラル形式という構造になっています。

## 🧩 なぜ型付きリテラルが便利なのか？

- `hex[FF]` のように **型を意識したまま計算できる**  
- `to_hex(x)` を使えば **結果を hex[…] 形式で表示できる**  
- 日時計算では `datetime[]` が **視覚的に分かりやすい**  
- Excel のセル書式のように **「値＋型」を自然に扱える**

PasoCalc の「構造化された計算モデル」と非常に相性が良く、  
複雑な計算でも **型の混乱が起きない**のが特徴です。
