# PasoCalc — 電卓の軽さで、Excel のように計算できる行ベース計算ツール

**PasoCalc は、電卓の手軽さと Excel の柔軟性を両立した “行ベースの数式ワークスペース” です。**  
行ごとに数式を入力し、上から順に評価されるため、計算結果を自然に参照しながら連続計算できます。

Excel を開くほどではないけれど、電卓では物足りない──  
そんな場面に最適化した軽量計算ツールです。

## ✨ 特徴

### ✔ 行ベースの計算モデル  
- 各行は「変数名・別名・数式・結果」を持つ  
- 上から順に自動計算され、依存関係が自然に解決  
- 行の追加・削除・並び替えでも壊れない **internalId 管理**  
- `[alias]` 記法で任意の別名を変数として利用可能

### ✔ 高速で安全な式評価  
- exp4j による高速評価  
- `sin_deg`, `cos_deg`, `tan_deg` など **度数法関数を独自拡張**  
- `^` を自動で `pow(a, b)` に変換  
- 数式の書き心地を最大限シンプルに

### ✔ 実用的でシンプルな UI  
- ダーク／ライトテーマ  
- メモ欄（別ウィンドウ編集対応）  
- 関数一覧パネル  
- ショートカットキー  
  - Ctrl+↑ / Ctrl+↓（行移動）  
  - Ctrl+D（行複製）  
  - Ctrl+BS（行削除）  
  - Ctrl+R（再計算）  

### ✔ JSON 保存／読み込み  
- `.pcale` ファイルとして計算状態を丸ごと保存  
- コメント・丸め桁数・行データを完全復元  
- 計算ログとしても活用可能

- Windows 10 / 11

- レジストリ未使用  

## ▶️ 使い方

1. ZIP を展開して `PasoCalc.exe` を起動  
2. 行に数式を入力（例：`1+1`）  
3. Enter または Tab で計算  
4. 別名（例：`a`, `b`, `temp1`）を設定すると、  
   下の行で `[a]` のように参照可能  
5. 「下に追加」ボタンで行を追加  
6. 行を上から順に評価し、依存関係を自動解決

### 数式例（2次方程式）

```
例:二次方程式の解
a = 2
b = 8
c = 4
temp1 = sqrt(([b]^2) - 4 * [a] * [c])
x1 = (-[b] + [temp1]) / (2 * [a])
x2 = (-[b] - [temp1]) / (2 * [a])
```
