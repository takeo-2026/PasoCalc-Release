# PasoCalc — PC のための軽量・構造化された電卓アプリ

**PasoCalcは、計算を「行」として残しながら組み立てられる、Windows向けの軽量電卓です。**

電卓の手軽さと、Excelのような計算結果の再利用を両立。

**数式を上から並べるだけで、途中計算を残したまま計算できます。**

## ✨ 特徴

* 数式を行単位で管理
* 別名による計算結果の再利用
* 度数法などの便利な数学関数
* 16進数・2進数・日時の計算
* 計算内容を `.pcale` ファイルに保存
* ダーク／ライトテーマ
* メモ機能
* キーボードショートカット

## 🖥️ 動作環境

* Windows 10 / 11
* インストール不要
* ZIP展開のみ
* レジストリ未使用

## ▶️ 使い方

1. ZIP を展開して `PasoCalc.exe` を起動  
2. 行に数式を入力（例：`1+1`）  
3. Enter または Tab で計算  
4. 別名（例：`a`, `b`, `temp1`）を設定すると、  
   下の行で `[a]` のように参照可能  
5. 「下に追加」ボタンで行を追加
